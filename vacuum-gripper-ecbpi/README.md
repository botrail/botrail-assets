# vacuum-gripper-ecbpi

**詳細モデル**: [authoring/README.md](authoring/README.md)。
カタログの既存revと最新の著作USDは同一とは限りません。利用するrevと取得コミットを確認してください。
公式の現行図面は **4-M4 / PCD 46 mm**、本体質量は **775 g**。
以下にある旧 r1 の「3穴」「750 g」は改善版には採用しない。
旧 URDF/STL は再現用に残しており、r1 の3穴アダプタは r2 と非互換。

コボット向け電動真空グリッパの自作アセット。CC0-1.0。

カタログに `gripper.vacuum` カテゴリのモデルが 1 つも無かったのを埋めるために著作した。
吸着系はベンダー製のオープンな 3D モデルが**一つも存在しない**カテゴリで
(OnRobot VG10 / VGC10、Robotiq EPick、Schmalz、SMC を確認。公式 CAD はいずれも
要ログイン、ROS の description パッケージも無し)、**実機を 1 つ参照モデルに定め、
その公表値に寸法を合わせた独自著作**にしてある。

## 参照実機

**Schmalz CobotPump ECBPi** (ECBPi 12 24V-DC M12-8) — コボット用の電動真空発生器。
バヨネットで吸着エンドエフェクタを工具レス交換する構成。

出典: [Schmalz 公式製品ページ 技術データ](https://www.schmalz.com/en/products/vacuum-technology-for-automation-301607/vacuum-components-301608/vacuum-generators-307617/electric-vacuum-generators-738973/electric-vacuum-generators-end-of-arm-739374/vacuum-generators-ecbpi-308294/10.03.01.00314)
(寸法記号 D / D2 / L / Dmk1 は取扱説明書 §4.5 Dimensions、負荷限界は §4.4 と同一)

### 参照実機から採った値

| 項目 | ECBPi の公表値 | 本アセット |
|---|---|---|
| 外形 D | ø151.5 mm (**丸みを帯びた三角断面**) | **ø151.5 / 三角断面** (一致) |
| 上部ボス D2 | ø76 mm | **ø76 mm** (一致) |
| 全高 L | 88.6 mm | **88.6 mm** (一致、本体下端まで) |
| 質量 | 0.75 kg | 0.75 kg + カップ分 (下記) |
| 負荷限界 (水平取付) | max 100 N | **100 N** を定格として採用 |
| 負荷限界 (垂直取付, L=100mm) | max 25 N | メタデータのみ |
| 最大真空 | 75% | **75%** (一致) |
| 取付 | 3 x M4 / ボルト円 ø46 (Dmk1) / ねじ深さ 6 | **一致** (ISO 9409-1 ではない) |
| 吸込量 | 0–12 L/min | **12 L/min** (一致) |
| エンドエフェクタ取付 | バヨネット (工具レス) | 形状として再現 |

胴が**円筒ではなく丸みを帯びた三角断面**なのが実機の姿。参照実機を見ずに作ると
まず円筒にしてしまうので特記しておく。

### 参照実機から意図的に変えた点

| 項目 | ECBPi | 本アセット | 理由 |
|---|---|---|---|
| 吸着エンドエフェクタ | 別売 (2 or 4 カップ / ベローズ or フラットの選択制) | **ø40 ベローズカップ x 4 + プレート** を当方で設計 | ポンプ単体では把持できないため。実機の選択肢のうち 4 カップ・ベローズ構成に相当 |
| 質量 | 0.75 kg | **1.0 kg** | 上記プレート + カップ分 (0.25 kg) の追加 |

**外観 (面取り・パネル位置・バヨネット爪・カップ形状) はすべて独自著作。**

### 可搬の考え方

定格は参照実機の**水平取付 100 N (約 10 kg)** をそのまま採る。ø40 カップ 4 個の
理論吸着力は 75% 真空で 1 個あたり約 94 N (= 75 kPa x π x 0.02²) なので合計は
これを大きく上回り、**律速するのはカップではなくポンプ/取付側**。

## フレーム

```
mount (ロボットフランジ接触面, ISO 9409-1-50-4-M6)
  -> body   本体 88.6 mm + 吸着プレート 7.4 mm
  -> tcp    カップ接触面 = mount から 118 mm
```

## 生成

```sh
python vacuum-gripper-ecbpi/tools/generate_meshes.py
```

胴は 3 ローブ断面 `r(θ) = (r_max - amp) + amp·cos(3θ)` のロフト、カップは回転体。

collision は URDF プリミティブのみ。三角断面の胴は**中央 1 本 + ローブ 3 本の円柱**で
近似してある — 外接円 1 本で包むと 3 面の平らな部分が 28 mm も太るため。
表示パネルは胴から約 10 mm 出るので別途 box を持たせている。
