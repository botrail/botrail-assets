# ダイヘン Welbee Inverter P350L II (WB-P352L)

実在する **DAIHEN WB-P352L** を参照した、CC0-1.0 の独自著作モデル。
メーカー CAD・写真・テクスチャ・寸法図は同梱していない。
カタログ ID `daihen/welbee/wb-p352l/r2`（公開前）。旧外観の `r1` は以前のコミットを固定参照する。

対象は高さ 640 mm の **P350L II**。WB-P502L / P500L II は高さ **810 mm** の別筐体であり、
同寸法ではない。ワイヤ送給装置 CM-7403、トーチ、ケーブル、水冷循環装置は含まない。

## 一次資料と採った値

- [DAIHEN 公式製品ページ](https://www.daihen.co.jp/products/welder/mig/p502l.html): 型名対応
- [Welbee II 公式カタログ](https://www.daihen.co.jp/products/welder/pdf/co2_mag/Welbee2kaitei.pdf):
  2025 年 4 月、CAT. NO. B222404。表紙の実機写真、p7 の USB / 背面、p9 の仕様
- [Hammer 420SR-R50 公式仕様](https://www.hammer-caster.co.jp/products/detail/3594)と
  [旧 RD50 掲載カタログ p28](https://www.hammer-caster.co.jp/catalog_en/pdf/63.pdf)・
  [取付寸法 p27](https://www.hammer-caster.co.jp/catalog_en/pdf/62.pdf): 近似に使用するキャスタ自体の寸法

出典の版、SHA-256、確認済み事項と推定の区別は [provenance.json](./authoring/provenance.json) に記録した。
原資料は参照専用。著作権のある図面・写真を CC0 として再配布するものではない。

| 項目 | 出典の事実 | 本モデル |
| --- | --- | --- |
| 幅 × 奥行 × 高さ | 395 × 710 × 640 mm、アイボルトを除く。高さは床から前面上端まで | アイボルト以外の visual 包絡を同寸法で検証 |
| 車軸配置 | 旧モデルの互換値: 左右 320、前後 460、後方張出 100 mm | 車輪中心 x = ±160、y = −205 / +255 mm を保持。今回の適格資料で実機寸法を再検証した値ではない |
| キャスタ | 写真に小径の車輪。実機搭載部品の同定は今回の適格資料では未確定 | 4 個の固定車輪の近似。旋回やブレーキは追加しない |
| 車輪寸法 | 現行 Hammer 420SR-R50 の公式値: Ø50 × 26、取付高さ 70 mm | 写真の小径車輪を表す近似として採用。実機搭載部品と同一とは認定していない |
| 質量 | 54 kg | 参照仕様のみ。未同定の重心・慣性は URDF に書かない |
| 定格 | 三相 200 / 220 V、主たる MAG / パルス条件 350 A・使用率 60% | 参照情報。電気・溶接・熱性能は模擬しない |
| 前面構成 | 大きい上段 + 小さい下段、左に各 11 スロット | 上段の後傾、独立した下段、実際に抜ける 11 穴ずつ |
| 吊り金具 | 前左・後右の対角 2 個 | 穴のあるリング 2 個。旧モデルの中央の棒は廃止 |

旧モデルの Ø80 mm 車輪は、写真に見える小径車輪を表す Ø50 mm の近似へ変更した。
50 × 26 mm・取付高さ 70 mm は Hammer の現行仕様と旧 RD50 掲載カタログの公表値であり、WB-P352L の搭載部品そのものの
確定寸法ではない。正確な足回りが必要な用途では実機の確認が必要。

参照調査では旧モデルが挙げた取扱説明書も確認したが、転載禁止の記載があるため、
CONTRIBUTING.md に従い **今回の新しい寸法の根拠には採用しない**。
車軸配置は旧モデルからの互換値を保持したもので、出典を新たに認証したものではない。
部品名・材質・背面の厳密な型番対応を、この資料を根拠に確定値とは扱わない。
背面は公開カタログのシリーズ写真を参照した推定形状であり、細部の実機一致は未検証。

## 作り込んだ形状と限界

- 前面は一枚の箱ではなく、後傾した上段の成形枠、ほぼ垂直な下段、別々の奥まった操作面と端子面
- 左前面の 11 穴 × 2 バンク、左側面の 4 列の通風穴と立体ルーバー、背面の通風穴
- 実際に穴を通して奥が見える出力端子、2 個のアイボルト、固定キャスタの車輪・ハブ・フォーク
- 背面の外部接続カバー、4 個のグロメット、入力端子のカバー、ケーブルクランプ
- 操作面の 2 表示窓・LCD・2 ノブ・USB カバー。運搬用ハンドルは資料で確認できないため追加しない

前面の傾き、成形枠の曲面、板厚、開口幅、端子・ノブ・金具の位置と寸法は **写真からの独自推定**。
側面ルーバーは 4 列を確認し、17 段の配置は近似として著作した。内部機器、ねじ山、機密部品、
隠れた底面構造、警告文字やメーカーの印刷意匠は複製しない。表示窓は無通電の表現、ラベルは無地。
オプションの水冷接続部は閉じたブランクとして表す。各部品は閉じたソリッドだが、全筐体を融合した
単一の防水ソリッドではない。製造・施工・安全検証に用いる精密 CAD ではない。

## 座標と互換性

- SI 単位、+Z 上、−Y が操作面
- `base_link`: 筐体中心直下の床面。4 輪が z = 0 に接する
- `mount`: `base_link` と同位置・同方向
- `torch_outlet`: トーチ側出力端子（前面下段右の対の右側）の真鍮リップ前面の中心 `[0.136, -0.326, 0.195] m`、
  向きは `base_link` と同じ（2026-10-10 改訂。旧版は前面左の概略マーカー `[-0.060, -0.355, 0.300]`）。
  写真からの推定位置で、実機のトーチ端子中心を測定したフレームではない

公開カタログの実機写真では出力端子は前面下段の右側、トーチ側はその右の端子である。
collision は旧来の筐体と車軸台の 2 個の box に、屋根の上に出る 2 個の吊り金具の box を加えたもので、
visual 全体を囲む（2026-10-10）。通風孔や車輪フォークを再現する接触形状ではなく、設置・干渉確認用の包絡。
車輪の転がり、電気接続は扱わない。

## 再生成・検証・表示

リポジトリのルートから、Node.js 22 以上:

```sh
npm --prefix authoring ci --ignore-scripts --no-audit --no-fund
node --test daihen-wb-p352l/authoring/model.test.mjs
node daihen-wb-p352l/authoring/export.mjs --check
python3 daihen-wb-p352l/authoring/verify_obj.py
```

編集後の意図した再生成:

```sh
node daihen-wb-p352l/authoring/export.mjs
python3 -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765/daihen-wb-p352l/authoring/` を開く。
`--check` とテストは生成物を上書きせず、再生成内容との一致を確認する。

OBJ は製品側の `compact-obj.mjs` で同じオブジェクト内の完全に同じ v / vt / vn 記録を再利用し、
約 19.9 MB から約 5.2 MB に縮小する。数値の丸め・面の削減は行わず、全コーナーの位置・UV・法線と
面・オブジェクト・材質の順序を厳密に比較する。頂点番号やファイルのバイト列は変わるが、描画形状は同じ。
別オブジェクト同士の頂点は共通化せず、他モデルの共通 exporter も変更しない。

Blender 4.x の静止画確認:

```sh
node daihen-wb-p352l/authoring/export-materials.mjs > /tmp/daihen-materials.json
blender -b -t 6 --python daihen-wb-p352l/authoring/render_review.py -- \
  daihen-wb-p352l/urdf/daihen-wb-p352l.urdf /tmp/daihen.png --view iso --materials /tmp/daihen-materials.json
```

[同条件の変更前後比較](./docs/before-after.png)・[背面／側面確認](./docs/detail-views.png)・
[検証記録](./docs/verification.md)。静止画は実際の OBJ / MTL / URDF を読み込み、両版に同じカメラ・照明を使用。
ブラウザによる実操作テストは実行環境の制約で未確認であり、静止画検証と区別する。
