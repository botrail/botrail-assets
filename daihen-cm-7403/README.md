# ダイヘン ワイヤ送給装置 CM-7403 — 独自形状の参照モデル

参照実機: **ダイヘン ワイヤ送給装置 CM-7403 (空冷、鉄用。Welbee Co-R の送給装置)**。カタログ `daihen/cm/cm-7403/r1`。CC0-1.0。
メーカー CAD・画像・第三者メッシュを使わず、取扱説明書の仕様表と外形図から著作した。CMV-7403 / CMW-7403 (水冷) は同じ外形。

出典: [CM-7403 / CMV-7403 / CMW-7403 取扱説明書](https://www.daihen.co.jp/products/welder/pdf/manual/wirefeeder/CM-7403_CMV-7403_CMW-7403.pdf)
(sha256 5bd27fb4b6892d8995ae7fff574cbdbb0448e06348e8e1d67776989f65a2f02b) 10.1 仕様・10.4 外形図。

| 項目 | 出典値 | 本モデル |
| --- | --- | --- |
| 外形 (W × D × H) | 254 × 611 × 393 mm | 筐体 254 × 370 × 363 + 上面カバー 30 (= 393)、後部のスプールホルダ 239 × 241 × 290。611 は筐体前端からホルダ後端まで |
| 取付 | 4 × M6、185 × 475 mm (外形図)、取付面が底 | 底面 z = 0 にパターン中心を置く。穴は前端から 80 mm |
| スプール | 最大 Ø300 × 103 mm、25 kg、ホルダは 15° 傾斜 | ホルダ +X 側面に Ø300 × 103 のスプール (軸を X から 15° 起こす)。後端から約 70 mm はみ出す |
| ワイヤ・送給速度 | 0.9–1.2 (0.6–1.6) mm、最大 22 m/min | specs の値 |
| 質量 | 14 kg (スプール除く) | specs の参照値。慣性は未同定 |

スプールの位置と高さ、ホルダの高さ、カバー・窓・トーチ接続口の位置は外形図の見た目から置いたもので寸法の根拠は無い。

## フレーム

- root の `base_link` = 取付面 (4 × M6 パターンの中心)、+Z が筐体の上方向、+Y が筐体前面 (トーチ接続側)、スプールは −Y 側の +X 面。
- `mount` = `base_link` と同位置・同向き (架台・ブラケットの取付面)。
- `torch_outlet_frame` = 前面のトーチ側パワーケーブル接続口、+Z が前方 (+Y) を向く。
