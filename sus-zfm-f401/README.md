参照実機: **SUS CRX シリーズ専用台車 A (アウトリガー付) ZFM-F401** (ZF 高剛性アルミ構造材。ファナック CRX-10iA / CRX-10iA/L 用)。
カタログ `sus/zfm/zfm-f401/r1`。CC0-1.0。メーカー CAD・画像・第三者メッシュを使わず、製品ページのラインアップ表と寸法図の数値から著作した。
アウトリガーなしの B (ZFM-F402、122 kg) は未収載。

## フレーム

- root の `base_link` = 本体 (850 × 700) の中心直下の床面、+Z 上。X が長さ (850)、Y が幅 (700)。+X がロボット側、−X が取っ手側。
- `mount` = `base_link` と同位置・同向き (床に置く契約)。
- `robot_mount` = ロボット取付プレート上面の中心 `[0.220, 0, 0.720]` (CRX-10iA の基部が載る)。向きは `base_link` と同じ。
