# misumi-hfs6 — ミスミ アルミフレーム 6 シリーズ HFS6-3030 の断面

カタログのフレームシステムパック `misumi/hfs/6-series/r2` (`structure.frame`、生成器 `frame_unit`) が
押出材 `profile_3030` の `components[].visual` から参照する USD レイヤ (CC0-1.0)。botrail は
部材の箱 (干渉の実体) にこの断面を被せ、長さ方向だけ切断長に伸ばして部材の向きに回す。
断面を持たないパックは botrail の汎用 T スロット形状 (`workshop-shapes/tslot`) で描かれる。

- **参照実機**: ミスミ アルミフレーム 6 シリーズ 正方形 30×30 mm 1 列溝 4 面溝、HFS (標準タイプ)。
  出所は製品ページの外形図 (2026-09-28 閲覧)。**メーカー CAD は使っていない** — 公表寸法から起こした
  独自著作で、溝の室の傾斜は図の比率からの近似。加工・組付けの寸法には使えない
- **`trim` ではなく `visual`、しかも長さ方向スケール**: 押出材は 0.5 mm 単位で切って売られるので、
  1 つの prim が売られている全長さを描く。断面は実寸 (m)、長さは 1 m を原点中心 (z ∈ [−0.5, 0.5])
  で著作し、利用側が z だけ切断長に伸ばす
- **穴は実形状**: 各面の溝 (開口 8) と室、芯の φ6.8 の穴、四隅の φ4.2 の穴は貫通していて、
  切り口から向こうが透ける
- **干渉には入らない**。当たり判定は botrail が置く部材の箱 (30 角 × 切断長) が持つ

| 項目 | 公表値 (外形図) | モデル |
|---|---|---|
| 外形 | 30 × 30、4×R2 | 同じ (角は 2 次曲線で丸め) |
| 溝 | 開口 8、リップ厚 2、室の幅 16.5 (深さ 2)、深さ 9、芯 12 | 室は 16.5 → 12 の台形 (壁の傾斜は近似) |
| 穴 | 芯 φ6.8、四隅 4×φ4.2 (ピッチ 23.2) | 同じ |
| 質量・断面性能 | 0.9 kg/m、333 mm²、Ix = Iy 2.83×10⁴ | 持たない (パックが持つ) |

| prim | 原点 | 描くもの |
|---|---|---|
| `/HFS6/profile_3030` | 断面の中心、長さ 1 m の中央 | 上の断面の押出し。仕上げ `anodised_aluminium` (黒アルマイトは利用側が tint) |

色は linear RGB、metalness / roughness は著作した値で測定値ではない。

## 再生成と検証

```sh
cd misumi-hfs6/authoring
npm ci
npm test          # 包絡・溝と穴の実在 (レイで確認)・prim 構成・出力の再現性
npm run export    # ../usd/hfs6-3030.usda
npm run check
```

[共通著作ライブラリ](../authoring/README.md) (`@botrail/authoring`) を使う。寸法を変えるときは
`profile.mjs` の `DIM` を変えて新 rev にする。
