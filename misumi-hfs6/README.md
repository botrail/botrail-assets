# misumi-hfs6 — ミスミ アルミフレーム 6 シリーズの断面と金具

カタログのフレームシステムパック `misumi/hfs/6-series` (`structure.frame`、生成器 `frame_unit`) が
`components[].visual` から参照する USD レイヤ (CC0-1.0)。押出材 HFS6-3030 / 3060 / 6060 の断面、
フレームキャップ HFC6 (3030 / 3060 / 6060)、ブラケット HBLFS6。botrail は部材の箱 (干渉の実体) に
断面を被せて長さ方向だけ切断長に伸ばし、継手の入隅にブラケットを、切り口にキャップを回して置く。
絵を持たないパックは botrail の汎用形状 (`workshop-shapes/tslot`・`tslot_2`・`bracket`) で描かれる。

- **参照実機**: ミスミ アルミフレーム 6 シリーズ (溝幅 8 mm) — 正方形 30×30 1 列溝 (HFS6-3030)、
  長方形 30×60 2 列溝 (HFS6-3060)、正方形 60×60 2 列溝 (HFS6-6060)、フレームキャップ HFC6-3030-B /
  3060-B / 6060-B、突起付ブラケット HBLFS6。出所は各製品ページの外形図 (2026-09-28 閲覧)。
  **メーカー CAD は使っていない** — 公表寸法から起こした独自著作で、溝の室の傾斜・大断面の空洞の形・
  キャップの突起径・ブラケットのリブ厚は図の比率からの近似。加工・組付けの寸法には使えない
- **押出材は `visual` + 長さ方向スケール**: 0.5 mm 単位で切って売られるので、1 つの prim が売られている
  全長さを描く。断面は実寸 (m、x が `w`・y が `d`)、長さは 1 m を原点中心 (z ∈ [−0.5, 0.5]) で著作し、
  利用側が z だけ切断長に伸ばす
- **キャップとブラケットは実寸の固定形**: キャップは断面の座標系 (x = `w`、y = `d`) の板で、板厚の中心を
  原点、外側の面が +Z、突起は −Z へ (押出材の穴に入る)。利用側は +Z を部材の外向きに回し、原点を
  切り口から板厚の半分だけ外に置く。ブラケットは**折り目の角が原点**、フランジは +X と +Y へ、
  幅は Z の中心で、利用側が 2 本の部材の入隅に角を合わせる
- **穴は実形状**: 溝と室、芯の φ6.8、四隅の φ4.2、大断面の空洞、ブラケットのボルト穴は貫通していて
  向こうが透ける
- **干渉には入らない**。当たり判定は botrail が置く箱 (断面 × 切断長、金具の外形箱) が持つ

## レイヤと prim

| `usd/` | prim | 原点 | 仕上げ |
|---|---|---|---|
| `hfs6-3030.usda` | `/HFS6/profile_3030` | 断面の中心、長さ 1 m の中央 | `anodised_aluminium` (黒アルマイトは利用側が tint) |
| `hfs6-3060.usda` | `/HFS6/profile_3060` | 同上 (x = 30 の辺、y = 60 の辺) | 同上 |
| `hfs6-6060.usda` | `/HFS6/profile_6060` | 同上 | 同上 |
| `hfc6-caps.usda` | `/HFS6/cap_3030`・`cap_3060`・`cap_6060` | 板厚の中心、外側の面が +Z | `black_polyamide` |
| `hblfs6.usda` | `/HFS6/bracket` | 折り目の角、幅の中心 | `die_cast_aluminium` |

`hfs6-3030.usda` は初版 (r2 のパックが参照) からバイト同一。色は linear RGB、metalness / roughness は
著作した値で測定値ではない。

## 再生成と検証

```sh
cd misumi-hfs6/authoring
npm ci
npm test          # 包絡・溝と穴と空洞の実在 (レイで確認)・キャップの突起・ブラケットの穴とリブ・prim 構成・出力の再現性
npm run export    # ../usd/*.usda (5 レイヤ)
npm run check
```

[共通著作ライブラリ](../authoring/README.md) (`@botrail/authoring`) を使う。寸法を変えるときは
`profile.mjs` の `DIM` / `PROFILES`、`hardware.mjs` の `CAPS` / `BRACKET` を変えて新 rev にする。
