# FANUC SR-3iA — 独自形状の参照モデル

参照実機は **FANUC SR-3iA (4 軸スカラロボット、床置き)**。CC0-1.0。
外装・ボールねじスプライン・ケーブルホースを Three.js で独自著作し、OBJ / MTL / URDF に出力する。
メーカー CAD、図面のトレース、第三者メッシュは含まない。
カタログ ID: `fanuc/sr3ia/sr-3ia/r1`。

## ケーブルホースの表現

外観だけの近似で、collision は持たない。3 本に分けて関節軸の上でつなぎ、どの姿勢でも切れて見えないようにした:

- 後半 (ベース): コネクタボックス上のグランドから J1 の後方 104.5 mm で立ち上がり (下端 100 mm は保護スプリング)、
  J1 軸の真上の点 Q (中心線の高さ 528 mm) まで
- 前半 (第 1 アーム): Q からヘッド上の点 P まで。P は J2 軸の上にあり、ホースはそこで鉛直になる
- 端部 (ヘッド): P からヘッド上面のコネクタまでの短い保護スプリング

Q・P とも関節軸の上にあるので、J1・J2 を回しても端点は一致する (テストで確認)。ただし J1 を回すと
Q でホースが折れ曲がる (頂点に置いた球で継ぎ目を隠している)。実機のホースは全体がしなって追従するので、
姿勢によって形は実機と異なる。図ではヘッド側の保護スプリングが斜めに入るが、本モデルは P で鉛直にしてある。

## 表現範囲

`flange` (= `tool0`) はスプライン軸下端の中心、+Z が軸方向 (鉛直下向き)。
工具取付部 (軸端の寸法・ツールフランジのオプション) は数値が無いため描かず、適合も宣言しない。
外装はロフトした角丸断面・円筒・面取り箱で近似。ボールねじの溝は見た目だけのらせん。

collision は独立した box / cylinder の近似 (基部・第 1 アーム・ヘッド・スプライン軸・カラー)。
描くリンクはすべて自前のプリミティブを持つ (持たないリンクは表示メッシュで照合されるため)。
スプライン軸はヘッドを貫通するが、ヘッドと軸は関節で隣り合うリンクなので自己干渉の対象外。
J3 = 0 でカラー (J4) とヘッド下のテーパ部の collision の間は 7 mm あけてある。
J1 = 0° では J2 の全範囲・J3 の全ストロークで自己干渉しない。J2 を ±135° より深く曲げ、J1 も同じ向きに
大きく振った姿勢 (乱択姿勢の約 2 %) では J4 軸がベース後部の上に来て、スプライン軸・カラーがベースと干渉する —
実機でも干渉する姿勢で、許可していない。
姿勢計画用の参照モデルであり、実機校正・動力学・サイクルタイムの保証はない。

## 再生成・表示

リポジトリのルートで:

```sh
npm --prefix fanuc-sr-3ia/authoring ci
npm --prefix fanuc-sr-3ia/authoring run export
npm --prefix fanuc-sr-3ia/authoring test
npm --prefix fanuc-sr-3ia/authoring run check
python3 -m http.server 8737 --bind 127.0.0.1
# http://127.0.0.1:8737/fanuc-sr-3ia/authoring/
```

URDF は `urdf/fanuc-sr-3ia.urdf`。USD は catalog-builder が生成する。
