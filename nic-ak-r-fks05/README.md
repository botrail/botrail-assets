# NIC AK-R-FKS05 (協働ロボット 5 kg 可搬以下用スタンド型架台) — 独自形状の参照モデル

参照実機: **エヌアイシ・オートテック 協働ロボット 5kg 可搬以下用スタンド型架台 AK-R-FKS05** (アルファフレーム製、UR3e / UR5e 用のロボットベースセット FKS05-UR-001 / -002 と組む)。
カタログ `nic_autotec/ak-r/ak-r-fks05/r1`。CC0-1.0。メーカー CAD・画像・第三者メッシュを使わず、製品ページの仕様と仕様図の寸法から著作した。

出典: [NIC 製品ページ](https://www.nic-inc.co.jp/products/robot/ak-r-fks05/) (仕様表と仕様図)、
[ミスミ掲載ページ](https://jp.misumi-ec.com/vona2/detail/221304073439/) (型番リスト、ロボットベースセットの仕様)。2026-10-06 取得。

**図の比率から置いたもの (寸法の根拠は無い)**: 横桁の奥行 90 mm、ノブ付きアジャスタとキャスタの位置、車輪径 Φ75、柱の左右の取っ手。
仕様図はロボットベースを Φ160 程度に描いているが、ミスミ掲載ページの記載 (Φ200) を採った。

## フレーム

- root の `base_link` = 台枠 (600 × 700) の中心直下の床面、+Z 上。X が幅 (600)、Y が奥行 (700)。柱は −Y 側に 100 mm。
- `mount` = `base_link` と同位置・同向き (床に置く契約)。
- `robot_mount` = ロボットベース上面の中心 `[0, −0.100, 0.800]` (ロボットの基部が載る)。向きは `base_link` と同じ。
  どちらの端が作業側かは資料に無いので、向きは利用側で決める。
