# mid-360

小型 3D LiDAR (Livox Mid-360 フォームファクタ) の自作マッシングモデル (CC0-1.0)。

> **Livox の CAD ではない。** 公式 STEP (mid-360-asm.stp) は公式サイトから
> ログイン無しで DL できるが利用条件の明記が無く再配布可否を判断できないため、
> 公式ユーザーマニュアルの公表寸法に合わせて独自に著作した簡略形状である。
> 実寸が要る用途には公式 STEP を使うこと。

## 寸法の根拠

出典: Livox Mid-360 User Manual (2024-04) Appendix "Livox Mid-360 Dimensions" と
"Coordinates"。

| 項目 | 値 | 出典 |
|---|---|---|
| 外形 | 65 × 65 × 60 mm (コネクタ込み幅 73) | 公表値 |
| 下部ブロック / ドーム | 高さ 39.5 / 上端 60 | 図面 |
| 点群原点 O | 底面から 47.0 mm | 図面 |
| 底面取付 | 4-M3 深さ 5 (48 × 36)、2-φ3 位置決め | 図面 |
| コネクタ | M12 航空コネクタ、底面から 16 | 図面 |
| 質量 | 265 g | 公表値 |
| フィンの本数・ドームの輪郭・角丸・コネクタの向き | — | **当方設計** |

## 座標系

- 原点 = `mount` = **底面中心** (実機は底面 4-M3 で取付)
- `livox_frame` = 点群原点 O、底面の 47.0 mm 上。+X = 前方 (Livox 座標系の X)、
  +Z = 上。コネクタは -X 側

## 再生成

```sh
python mid-360/tools/generate_meshes.py   # 依存: trimesh
```

`meshes/{base,dome}.stl` (メートル単位, Z-up) が更新される。collision は URDF の
プリミティブで、メッシュに依存しない。
