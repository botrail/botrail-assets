# OnRobot RG2 — 公式 STEP の実測に基づく独立した形状

参照実機: **OnRobot RG2、ツール側 Quick Changer、標準 EPDM フィンガーチップ**。
CC0-1.0 の手続き形状。メーカー CAD・メッシュ・写真・ロゴ・テクスチャは同梱しない。
カタログ ID `onrobot/rg/rg2/r3`（UR 接続構成、公開前）。旧外観・旧 TCP の `r1` と写真推定の `r2` は以前のコミットを固定参照する。

## 関節と TCP

- `rg2_v2_gripper_joint = 0` が全開（裸の指の間 110 mm、パッドの間 101.1 mm）
- 上限 1.2326 rad は**左右の標準パッドが接する角度**。パッドは裸の指より片側 4.45 mm 内側に出るので、
  裸の指どうしが接する角度（旧上限 1.30524 rad）より手前で閉じる。パッドの間の移動量は 101.1 mm
- 固定 TCP はパッドが接した姿勢での左右パッドの中心で、mount から 205.1 mm。開くとパッドは弧を描いて
  mount 側へ最大 38.6 mm 下がるので、開いた指先とは一致しない
- 閉じた姿勢のパッド先端は mount から 220.0 mm
- 速度 0.5 rad/s と effort 10 は旧シミュレーション値で、実機性能ではない

## 旧モデル（写真推定）からの変更（2026-10-11）

- **ピボットと本体が 13.6 mm 高すぎた**。旧 ROS 由来の高さはロボットフランジ（ロボット側 QC を含む）基準で、
  ロボット側 QC 109498 を別に挟む UR 接続構成では QC の厚さを二重に数えていた。TCP は 217.1 → 205.1 mm、閉時の先端は 232 → 220.0 mm
- 旧モデルはパッドの接触面を裸の指の面に置き、上限 1.30524 rad で左右のパッドが接していた。実物のパッドは 4.45 mm 内側に出る
- 本体は実測の輪郭（下端の楕円の角、首、S 字の広がり、丸い上端）と奥行きで作り直した。
  ブラケットは QC のスピゴット・青いリング・ベース・L 字の側板（上端は R20.5 の半円）・チルト円盤で作り直した
- リンクは奥行き 20 mm の一体のリンク（先端は二股）、キャリアは実測の輪郭の板、黒いカバー板はリンクの間を覆う位置にした
- collision はリンクごとの箱と円柱で、全リンクで visual を 1 µm 以内まで包む（例外なし）

## 重要な限界

- 黒いカバー板は、実物ではキャリアにピンで留まり外側リンクの上を滑る。モデルでは外側リンクに固定した板とし、
  リンクの間に入る内側のリブは省いた（固定するとリンクの間隔が狭まる閉じ側で内側リンクに当たる）
- 内側リンクの二股の溝は 43 mm から（実物は 47.4 mm）。簡略化したキャリアが閉じた姿勢で当たらないようにした
- 本体は殻として扱い、リンクが動く範囲の下（z 95.5 mm まで）だけ芯を置いた。頭部の側面は開いている
- チルト機構は 0° で固定（STEP は約 1.0° 傾いた状態で保存されていたので戻して測った）
- QC はツール側のスピゴットと青いリングだけ。ロボット側 QC は別アセット（109498）。ラッチ・接点・嵌合は作っていない
- リンク内部のはめ込み部品、スイッチ内部、内部のねじ・ピンは省いた。ピンとボスの重なりは表示上の接合で、実クリアランスではない
- 本体とブラケットは、本体の底がブラケットのベースに 1.0 mm 入る（固定継手）
- 自己干渉検査は離散姿勢のソリッド交差計算。連続全域の非干渉証明ではない
- 質量・慣性、接触力、弾性、安全スイッチ動作、ケーブル、実機の寸法公差は未検証
- [出典と不確かさ](./authoring/provenance.json)

## 再生成と検証

Node.js 22 以降。共通依存を準備して実行する。

```sh
npm --prefix authoring ci --ignore-scripts --no-audit --no-fund
node onrobot-rg2/authoring/export.mjs
node --test onrobot-rg2/authoring/model.test.mjs
node --test authoring/test/onrobot-contract.test.mjs
node onrobot-rg2/authoring/export.mjs --check
python3 onrobot-rg2/authoring/verify_obj.py
```

寸法は `authoring/model.mjs` の表（mm）に集め、形と関節は `authoring/visual-geometry.mjs`（RG6 と同一のファイル）が組み立てる。
両モデルの契約テストは双方のディレクトリを必要とする。[検証記録](./docs/verification.md)。
Three.js のビューアは `python3 -m http.server 8765 --bind 127.0.0.1` で配信し、
`/onrobot-rg2/authoring/` を開く。ブラウザ UI は本環境で未検証。
静止画は Blender 5.2.2 による実 OBJ / URDF のレンダーであり、ブラウザ操作の代用とはしない。
