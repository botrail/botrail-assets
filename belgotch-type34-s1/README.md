# マキテック ベルゴッチ Type34-S1 / 34CSH — visual trim

Type34-S1のアルミフレーム、緑ベルト、センタードライブと、別売固定脚34CSHを
参照したCC0の独自著作。寸法図・写真・メーカーCADは同梱しない。

| 項目 | 公表値 | モデル |
| --- | --- | --- |
| フレーム高 | 34 mm | 34 mm、標準の平坦な側枠 |
| 機幅 | 公称ベルト幅B＋40 mm | 同じ |
| ベルト実幅 | B−5 mm、機長4m超またはB=500/600はB−10 mm | 同じ条件分岐 |
| 機高 | ベルト天面から169 mm | 駆動部の最下端を同じ高さに配置 |
| プーリ | 駆動Ø76.3 / テールØ27.2 mm | 同径の円筒 |
| 脚高 | 搬送高さH−34 mm | 同じ |
| 脚ステー | 脚高500 mm未満は1本 | 同じ（HではなくH−34で判定） |
| 長尺仕様 | 機長6m超は中間テンション付き | 外観用ハウジングを追加 |

出典: [公式製品ページ](https://www.makitech.co.jp/conveyor/3/34-s1.html)、
[製品カタログ016頁](https://www.makitech.co.jp/support/download?id=5529)、
[脚カタログ100頁](https://www.makitech.co.jp/support/download?id=5651)、
[34CSH公開外形図](https://www.makitech.co.jp/support/download?id=601)。

`visual/unit.urdf.xacro` は `length`, `width`（公称B）, `height`（搬送H）をmで受け取る。
`visual/stand.urdf.xacro` は `width`, `height`, `leg`（脚の近似断面）をmで受け取る。
原点は床上中央、Xが搬送方向、Zが上。`equipment-common/` のマクロを同梱すること。
カタログが選んだ機長1500〜8000、幅200〜600、搬送高400〜1550 mmを対象とする。

意図的な近似: 駆動カバー長300・モータ張出し120・脚断面40・脚端部からの後退150 mm、
スロット、締結部、テンションカバー250×100 mmは外観用の推定値。駆動部は機長中央、
長尺テンションは機長の1/4位置に置く。実機のモータ出力別の包絡・取付位置ではない。
製品ページのベルト実幅条件を採用しており、旧レシピの「長尺かつ幅500/600」とは異なる。

脚は仮配置の2台。長尺時の必要脚数・許容荷重・モータ選定は発注先へ確認すること。
質量は未公表のまま補完しない。ベルトの実際の周回・張力・ローラ接触は再現しない。
visualは干渉に入れず、botrailが駆動部を含む近似ボックス包絡を持つ。
