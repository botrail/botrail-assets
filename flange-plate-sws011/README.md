# flange-plate-sws011

ISO 9409-1-50-4-M6 のロボットフランジと SCHUNK SWS-011 マスタ (SWK-011) を繋ぐ
ロボット側アダプタプレートの自作アセット。CC0-1.0。

## なぜ必要か

`tool-changer-sws011` の取付は SCHUNK 独自の **S7** (ボルト円 ø40) で
**ISO 9409-1 ではない**ため、ロボットフランジに直付けできない。これは実機の姿
そのままで、SCHUNK もロボット別のアダプタプレートを別売している。
その **ISO 呼び 50 向けの実物 A-SWK-011-ISO-A50 を参照実機**にした。

```
ロボットフランジ (ISO 9409-1-50-4-M6, UR3/UR5/UR10 等)
  -> [plate.mount .. plate.flange]   flange-plate-sws011          (25.5 mm)
  -> [master.mount .. coupling]      tool-changer-sws011-master   (15.5 mm)
  -> [tool.mount .. tool.flange]     tool-changer-sws011-tool     (20.6 mm)
  -> エンドエフェクタ                                    合計 61.6 mm
```

## 参照実機

**SCHUNK A-SWK-011-ISO-A50** (ID 0302223) —
[製品ページ](https://schunk.com/us/en/p/000000000000302223)。
寸法出典は **SCHUNK 公式 SWS カタログ p.28 "Adapter plate ISO-A50-R"** の公表図
(複製制限なしの通常カタログ。tool-changer-sws011/docs/step-measurements.md の追記参照)。

### 参照実機から採った値 (公表図)

| 項目 | 公表図 | 本アセット |
|---|---|---|
| 外径 | ø63 | **ø63** (一致) |
| 本体高さ | 25.5 | **25.5** (一致) |
| 全高 (パイロット込み) | 30.5 | **30.5** (一致) |
| ロボット側パイロット | ø31.5 (ISO 呼び 50 の位置決め径) | **一致** |
| ロボット側 | ISO 9409-1-50-4-M6 (ボルト円 ø50、ダウエル ø6) | **一致** |
| ツール側 | S7 (SWK を M3x25 x4 / ボルト円 ø40 で固定) | **一致** |

### 公式注記からの導出値

- **ツール側ポケット ø45 x 深さ 3.2**: カタログの SWS 011 Main view に
  「SWK のロボット側プレート (cover, ø45h7 x 厚 3.2) は**アダプタプレートに
  支持されることが必須**」と明記されている。その実装としてポケット深さを
  cover 厚と同じ 3.2 にし、cover 上面を面で支持する形にした
- ISO のボルト円 ø50 はポケット口 ø45 のすぐ外なので、M6 座ぐりはツール面の
  環状部 (幅 9 mm) に収まり干渉しない — **実機がこの寸法構成を選んでいる理由**が
  作ってみると分かる

### 設計値 (公表されていない部分)

- **中央通し穴 ø10** (ケーブル / エア通し。公表図に中央穴の記載なし)
- **質量 0.20 kg** (アルミ想定の体積推定。実機の重量は非公表)

### 兄弟品番 (未収録)

A-SWK-011-ISO-A31.5 (0302221, ø52 x 22.5) / A-SWK-011-ISO-A40 (0302222, ø63 x 30.5) /
SIP 版 (ピストンストローク監視つき、0302226-0302228)。

## 生成

```sh
python flange-plate-sws011/tools/generate_meshes.py
```

板は回転体 (閉じた `(r, z)` 輪郭) なので中央通し穴・パイロット・ポケットが
ブーリアン無しで出せる。ダウエルピン・ボルト縁・ねじ座は後付け。
