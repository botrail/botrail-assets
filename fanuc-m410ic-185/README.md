# FANUC M-410iC/185 — 独自形状の参照モデル

参照実機は **FANUC M-410iC/185 (4 軸パレタイジングロボット、ペデスタル形ベース)**。CC0-1.0。
外装・平行リンクを Three.js で独自著作し、OBJ / MTL / URDF に出力する。
メーカー CAD、図面のトレース、第三者メッシュは含まない。
今回の外観改訂のカタログ ID は `fanuc/m410ic/m410ic-185/r2`（公開前）。既存 r1 の参照 SHA は変更しない。

## 出典と採用値

- [FANUC M-410iC/185 データシート (FANUC America)](https://www.fanucamerica.com/docs/default-source/fanuc-robot-datasheets-new/datasheet-m-410ic-185.pdf):
  可搬・リーチ・軸数・動作範囲・最高速度・質量、および動作範囲図の寸法数値。
- [FANUC America M-410iC/185 製品ページ](https://www.fanucamerica.com/products/robot/m-410ic-185):
  当該 185 kg 型のペデスタル形製品写真と手首詳細写真を実画素で確認。
  写真のコピー・トレース・テクスチャ利用はしていない。
- 以前の出典 RM-410iC(E)-05 は複製禁止条項があるため、今回の著作・寸法資料から除外した。
  出典の用途と推定値は [provenance.json](authoring/provenance.json) に記録。

**J2 と J3 の範囲の分け方は推定**: データシートは各軸の角度幅だけを公表している。
本モデルは幅 144° / 136° を保ったまま、動作範囲図の上端 (2397 mm) と下端 (−561 mm) が
同時に再現される区切りを採った (J3 上限 +10° が上端を、J2 上限 +100° と J3 −90° が下端を決める)。
J3 は上腕の**水平からの角度** (平行リンクの絶対角) で、FANUC の J2/J3 連成の慣習に合わせてある。
URDF の独立した関節範囲では、実機の J2–J3 相互干渉制限 (動作範囲図の曲線部) は表せない —
両端の角を同時に使う姿勢は実機では届かない場合がある。

## 平行リンクの表現

- **J3 駆動**: J2 軸と同軸のクランクと、下腕に平行なロッドが上腕の後方レバーを押す。
  クランクとレバーの長さ・角度 (後方 510 mm・上方 270 mm) は既存モデルから継承した著作値。今回のメーカー寸法確認値ではない。
- **手首の水平保持**: 肘の三角プレートと、下腕・上腕それぞれに平行なロッドの 2 段の平行四辺形。
  上側ロッドの手首側ピンは手首回転軸から前方 485 mm・上方 279 mm (既存モデルから継承した著作値。
  上腕を −126°〜+10° のどこに振ってもロッドが上腕に当たらない向き)。プレートの寸法も著作値。

URDF では、下腕の上端に水平に戻す受動関節 `J2_level` (J2 に ×−1 で追従)、手首に
`J3_level` (J3 に ×−1) を置き、フェースプレートがどの姿勢でも下を向く。クランク・ロッド類は
`mimic` で J2 / J3 に追従するリンクで、指令軸は `J1`…`J4` の 4 本だけ。
上側ロッドの前端は手首ブラケットにピン結合されて常に重なるので、カタログの
`self_collision.allowed_pairs` にその 1 対 (`level_upper_link` × `wrist_link`) を宣言している。
水平保持ロッドは自分が並走する腕と描画上わずかに重なる (下側ロッドは下腕の肘シールと約 13 mm) ため、
下側ロッド × 下腕、上側ロッド × 上腕もカタログで許容対にする。

## 表現範囲

`flange` (= `tool0`) はフェースプレート中心、+Z が面の法線 (鉛直下向き)。
フランジのボルト・ピン穴は図面に数値が無いため描かず、ISO 規格適合も宣言しない。
外装は独自の断面 loft・面取り押し出し・円筒で近似。下腕の 3 つの肉抜きは、
従来の左右面の黒い薄板から、公式写真で見える前面の実際に奥行きがある凹部へ修正。
凹部の寸法と盲底構造は著作上の近似で、メーカー確認済みではない。
上腕・下腕の曲がりと断面遷移、開口付きのペデスタルと別体サービス筐体、手首の二股ブラケット、
軸端キャップと駆動側モータを更新した。台座の片側にサービス筐体を寄せ、反対側と前後の開口を残した。
ボルト表現は外観用で、取付インターフェースの穴パターンを表さない。
ケーブルは後部の保護スリーブと手首の短い保護リードのみ (掃引は検証しない)。

collision (2026-10-10) は描いた部品から求めた box と軸まわりの円柱 (鋳物は区間ごとの box、クランクのレバーは
傾けた box) で、各リンクの visual はすべて collision の内側にある。旧版の collision はロッドや肘プレートを腕から
離すために細く短くしていて、visual から最大 537 mm 外れていた。描くリンクはすべて自前のプリミティブを持つ
(持たないリンクは表示メッシュで照合されるため)。ピンで結ばれる部品同士は全姿勢で重なる (自動で許容される)。
ケーブル・製造公差は表さない。
上腕を真下に畳んだ姿勢 (J2 ≈ 0° / J3 ≈ −90°) では旋回胴・下腕と干渉する — 実機では J2/J3 の
相互干渉制限が禁じる姿勢で、許可していない。
姿勢計画用の参照モデルであり、実機校正・動力学・サイクルタイムの保証はない。

## 再生成・表示

リポジトリのルートで:

```sh
npm --prefix fanuc-m410ic-185/authoring ci
npm --prefix fanuc-m410ic-185/authoring run export
npm --prefix fanuc-m410ic-185/authoring test
npm --prefix fanuc-m410ic-185/authoring run check
python3 -m http.server 8737 --bind 127.0.0.1
# http://127.0.0.1:8737/fanuc-m410ic-185/authoring/
```

URDF は `urdf/fanuc-m410ic-185.urdf`。USD はカタログのビルド工程が生成する。
リンク・軸・mimic の契約は旧版と同じ。collision は 2026-10-10 に作り直した。
OBJ は属性の数値を丸めず、同一 object 内の完全一致レコードのみ共有して圧縮する。
