# SWA-011 STEP からの実測値 (2026-08-13)

## STEP の扱い — **メッシュのソースにはしない**

計測に使った STEP は CADENAS PARTserver 経由で入手した
`SCHUNK-0302317 SWA-011-000-000_.stp`。**ライセンスは CC BY-ND 4.0**
(データベース権: CADENAS GmbH / 原部品の権利: SCHUNK SE & Co. KG)。

**ND = NoDerivatives** なので:

- ❌ **STEP をテッセレートしたメッシュは「改変物」にあたり配布できない。**
  STEP パイプラインに通して出力を公開する道は塞がれている
- ✅ **STEP から読み取った寸法は事実 (facts) であり保護対象ではない。**
  その寸法から独自に形状を起こして CC0 で配布することはできる

したがって本アセットでは **STEP を「測定器」としてのみ使い、メッシュは読み取った
寸法から `tools/generate_meshes.py` が手続き的に再著作する**。STEP ファイル自体も
その派生物もリポジトリには置かない。

### 取付パターン = S7 (SWA と共通)

**穴中心 (x, z) = (±14.1, ±14.1) mm → ボルト円 ø39.9 ≒ ø40、45/135/225/315°**
— **SWA-011 と完全に同じ**。S7 が両半分で共通のパターンであることが実測で確認できた。

SWA 側は r = 2.1 の単純な通し穴 (ø4.2, M4 通し) だったのに対し、SWK 側は
r = 1.5 / 1.8 / 2.8 / 3.0 の**段付き穴** (座ぐり付き通し穴、またはめねじ + 座ぐり)。

### その他 (SWA と共通の特徴)

- **エア通し 6 ポート**: r = 1.4、中心が半径 17.5 mm 上 (ボルト円 ø35) — SWA と一致
- **側面のエアマニホールド**: r = 4.4 / 2.1 の穴が 3 方向 (0°, ±25°) — SWA と一致
- 主軸まわりの段付き径: r = 5.0 / 9.3 / 13.0 / 14.9 (カムボス + ピストン室)
- 半径 18.4 / 20.0 に r = 1.5 / 2.5 の穴 — ロック/アンロックのエアポートと推定

### 未解決 — 取付面の Y 位置

公表の高さ 15.5 mm に対し STEP の Y 全長は 40.81 mm。**どの Y 平面が S7 取付面
(公表 15.5 mm の基準) なのかが未確定**。
仮説: 板本体が Y = −12.504 … +2.996 (= 15.5 mm) で、+28.3 までの残り約 25 mm は
ピストン/検出シャフトまたはコネクタ類。**平面の抽出で要確認**。

SWA が「板 20.6 + 結合側の突起 3.19」ときれいに分かれたのと同じ切り分けができれば、
結合時の積み高さ 36.1 mm (= 15.5 + 20.6) と整合するはず。

## 平面抽出による決着 (Y に垂直な平面の位置と面積)

### SWA-011 — **確定**

| Y [mm] | 面積 [mm²] | 判定 |
|---|---|---|
| **−20.600** | 1317.8 | **ツール取付面** (ø50 の円板から中央穴 ø27 と 4-ø4.2 を引いた 1335 とほぼ一致) |
| **0.000** | 1227.5 | **結合面** (マスタと合わさる面) |
| +3.193 (突起先端) | — | 位置決めリング。マスタ側の凹みに入る |

→ **板厚 20.6 mm は Y = −20.600 … 0 で、公表値と完全一致**。

### SWK-011 — 取付面の割り当てが**未確定**

| Y [mm] | 面積 [mm²] |
|---|---|
| 21.700 | 1534.0 |
| 0.000 | 1264.4 |
| 18.500 | 714.7 |
| 17.300 | 530.9 |
| 15.500 | 223.4 |
| −12.500 | 112.6 |

Y = 0 と Y = 15.500 の差がちょうど公表の 15.5 mm になるが、Y = 15.500 の面積が
223.4 mm² と小さく、その上の Y = 21.700 に最大面 (1534.0) がある。
「取付面より上に材料がある」のは幾何的に不自然なので、
**向き (どちら側がロボットか) を含めて要再確認**。

なお結合時の積み高さは SWK 15.5 + SWA 20.6 = **36.1 mm** で公表値と一致するので、
15.5 という値自体は正しく取れている。

### SWK-011 — **確定** (半径分布で決着)

法線の符号は面の向き (REVERSED) を見ていないため当てにならないので、**半径範囲**で判定した。

| Y [mm] | 面積 [mm²] | r_max | 判定 |
|---|---|---|---|
| −12.500 | 112.6 | 7.80 | **カムボス先端** (下向きに突き出す) |
| **0.000** | 1264.4 | 24.50 | **結合面** (ø49 のほぼ全面。SWA の結合面と合わさる) |
| **15.500** | 195.4 | 24.50 | **板の外周リム上端** = 公表の高さ 15.5 mm の基準 |
| 17.3 / 18.5 | 530.9 | 13.00 | 内部段差 (ピストン室) |
| 21.700 | 1534.0 | 22.35 | 上部構造 (ピストンカバー) の面 |

→ **結合面 Y=0 から外周リム上端 Y=15.5 までが板本体 = 公表 15.5 mm と一致**。
その上は径が絞られた上部構造 (r 22.35) が Y=21.7 まで、さらに検出シャフト等が 28.3 まで。
