カタログ `nic_autotec/ak-r/ak-r-fkt10/r1`。CC0-1.0。メーカー CAD・画像・第三者メッシュを使わず、製品ページの仕様と仕様図の寸法から著作した。

**図の寸法を満たすように割り付けたもの (寸法の根拠は無い)**: 天面の押出材と上桁の重なり方 (上桁を 30 mm 高にして開口 548 と全高 800 を両立させた)、
キャスタの位置と車輪径 Φ75、取っ手の位置、底板を置く前後位置。
ロボットベースセット (t 20、ロボットごとの別型番) は溝に沿って任意の位置に付けられ、寸法が公開されていないので描いていない。

## フレーム

- root の `base_link` = 本体 (650 × 840) の中心直下の床面、+Z 上。X が幅 (650)、Y が奥行 (840)、+Y が取っ手と配線開口の側。
- `mount` = `base_link` と同位置・同向き (床に置く契約)。
- `robot_mount` = 天面の有効範囲 (590 × 630) の中心 `[0, −0.045, 0.800]`。ロボットベースセットを載せるとロボットの基部は 20 mm 上がる。
