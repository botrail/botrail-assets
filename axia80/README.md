# axia80

6 軸力覚センサ (ATI Axia80 フォームファクタ) の自作マッシングモデル (CC0-1.0)。

> **ATI Industrial Automation の CAD ではない。** ATI の CAD は製品ページのフォームの
> 先にあり再配布条件を判断できないため、製品フライヤに掲載された公開図面
> (Drawing # 9230-05-1507) の公表値に合わせて独自に著作した簡略形状である。
> 実寸 CAD が要る用途には ATI の CAD ダウンロードを使うこと。

## 寸法の根拠

出典: ATI Axia80 製品フライヤ (9205-05-1026、図面 9230-05-1507 掲載) と
製品ページ (ati.novanta.com、質量)。

| 項目 | 値 | 出典 |
|---|---|---|
| 外形 | φ82 × 25.4 mm | 図面 |
| 取付インタフェース (両面) | 6× M5×0.8 タップ 等配、B.C. φ71.12、位置決めピン穴 | 図面 |
| センシング基準座標系の原点 | ツール側の面の中心 | 図面 |
| コネクタ (M8 6 ピン) | 側面、取付面から 6.97、先端は中心から 50.2 | 図面 |
| 質量 | 0.3 kg | 製品ページ |
| 外周の黒帯・面取り、穴の省略 | — | **当方設計** |

M8/M20/M50 の 3 レンジは同一筐体で、キャリブレーション (定格) だけが違う。

## 座標系

- 原点 = `mount` = **取付面 (ロボット側) の中心**、+Z = ツール側
- `flange` = ツール側の面の中心 (mount の 25.4 mm 上)、+Z 外向き
- `ft_frame` = センシング基準座標系 (flange と同位置・同向き)。+X = LED 側 =
  コネクタ (-X) の反対

## 再生成

```sh
python axia80/tools/generate_meshes.py   # 依存: trimesh
```

`meshes/{body,band}.stl` (メートル単位, Z-up) が更新される。collision は URDF の
プリミティブで、メッシュに依存しない。
