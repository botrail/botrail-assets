# belt-conveyor

汎用ベルトコンベアユニットの**見た目**を持つアセット (CC0-1.0)。カタログの
`botrail/conveyor/belt-unit/r1` (`conveyor.belt`) が `components[].trim` から参照する。

- **メッシュは無い。プリミティブの xacro だけ** — コンベアは機長・幅・高さを指定して
  買う製品なので、形状ファイルにはできない。1 枚の xacro が売られている全寸法
  (機長 600〜5000 / 幅 150〜500 / 高さ 500〜1000) を描く
- **参照実機は特定していない** — 市場で一般的なアルミフレーム式コンベアを模した独自著作
- **干渉には入らない**。当たり判定は botrail が置くベルト板・側板・脚が持ち、
  ここのファイルはそれらの見た目とローラ・駆動部・貫・足を描く

## ファイル

| | 引数 (すべてメートル) | 描くもの |
|---|---|---|
| `visual/unit.urdf.xacro` | `length` `width` `height` `belt_thickness` `rail` | ベルト・側板・ヘッド/テールローラ・減速機・モータ |
| `visual/stand.urdf.xacro` | `height` `belt_thickness` `width` `leg` | 脚 2 本 + 貫 + 足。**台数と間隔はカタログの `rules.stand_span_max_mm` から生成器が決め**、1 台ぶんをここが描く |

原点はどちらも **床レベル・その部材の中心** (`height` = 床からベルト上面まで)。
円筒は +Z 軸なので、幅方向のローラは `rpy` で X 回りに 90 度倒してある。
