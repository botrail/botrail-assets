# trusco-pallet-rack

TRUSCO **重量パレットラック 1 トン用**(有効間口 2500 × 奥行 1100)の**見た目**を持つアセット(CC0-1.0)。
カタログの `trusco/pallet-rack/1d-2500x1100/r1`(`structure.rack`、生成器 `bt.parts.pallet_rack`)が
`components[].trim` から参照する。

- **メッシュは無い。プリミティブの xacro だけ** — 当たり判定は botrail が置く支柱とビームが持つ
- 参照実機: オレンジブック掲載の型式 1D-25/30/35/40B25-11-2/3(単体)と同 -B(連結)。
  例: [1D-30B25-11-2](https://www.orange-book.com/ja/c/products/index.html?itemCd=1D30B25112++++++++++++++++++++8000)

| 項目 | 公表値 | モデル |
| --- | --- | --- |
| 有効間口 / 奥行 | 2,500 / 1,100 mm | 同値 |
| 高さ | 2,500 / 3,000 / 3,500 / 4,000 mm | 同値 |
| ビーム段数 | 2 段(H2500–3500)、3 段(H4000) | 同値 |
| 均等積載 | 1,000 kg/段 | specs |
| 段調整ピッチ | 50 mm | ビーム高さはこの刻みに丸める |
| 質量(単体 / 連結) | 129.2/99.1、137.66/103.51、149.08/109.22、196/150 kg | variants 表 |
| 支柱断面・ビーム高 | **非公開** | 90 × 70 mm・ビーム 100 mm — 仮定(施工図には使えない) |

`visual/bay.urdf.xacro`: 1 間口分。引数 `width` `depth` `height` `upright` `upright_depth` `beam`(m)、`first`
(1 = 単体: 手前の支柱枠も描く / 0 = 連結: 隣と共有するので奥の枠だけ)、`z1` `z2` `z3`(各段ビーム上面の高さ、0 = 無し)。
原点は床レベル・間口の中心、X = 間口方向、Y = 奥行。支柱・足板・水平材・斜材・ビーム対と端部コネクタを描く。
