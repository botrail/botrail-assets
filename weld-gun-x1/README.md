# weld-gun-x1 — サーボスポットガン (X ガン / シザー式)

自動車 BIW 向け X 型サーボスポットガンの独自著作モデル (CC0-1.0)。
**特定メーカー製品の複製ではない**が、寸法と仕様は**公開規格と実機クラスの
公表値に合わせてある**(下の「寸法の根拠」参照)。

![外観](docs/gun-iso.webp)

## 構成

X 形 (シザー式) — 固定アームと可動アームがピボットで交差する。

- **1 DOF** (`electrode_joint`, revolute, 軸 `0 -1 0`): 可動電極アーム。
  **正方向 = 開**。`q=0` が閉、`q=0.26 rad` (14.9°) が全開
- **リンク**: `mount` (root = フランジ接触面) → `body` → `electrode_arm`。
  `tcp` = 固定電極先端 (body 側の固定子リンク)
- **body**: 取付フランジ板 + ブラケット溶接構造、MFDC トランス (冷却フィン・
  端子箱)、サーボ + ボールねじ駆動、ピボットクレビス、固定アーム + 固定電極
  (上向き)、冷却水マニホールド / ホース / キックレスケーブル
- **electrode_arm**: ピボットブレード + ボールねじ連結テール、可動アーム +
  可動電極 (下向き)、冷却ホース

## 寸法の根拠

スポットガンは受注設計のため、寸法図を公開しているメーカーが見つからない
(OBARA / NIMAK / Milco / ARO / Electroweld を確認)。そこで**公開規格と、
実機クラスで公表されている値**に合わせて著作した。

| 項目 | 値 | 根拠 |
|---|---|---|
| 電極キャップ | **ISO 5821 Type F, 16 × 20** | 規格表 d1=16 の行: l1=20, R1=40 (先端球面), テーパ 1:10 |
| 電極加圧力 | **4.0 kN** | 同表 ⌀16 キャップの `Fmax` = 4 kN |
| のど深さ | **400 mm** | X 型ガンで公開されている標準のど深さ |
| トランス | MFDC 160 kVA / 500 V 1000 Hz | OBARA DB3-160 クラスの公表値 |
| 質量 | 95 kg (body 78 + arm 17) | FANUC R-2000iC/165F 可搬 165 kg の範囲内 |
| 関節 effort | 1800 Nm | 4.0 kN × 電極までの腕 0.438 m |

電極キャップは規格どおり先端が R40 の球面で、張り出しは
`R1 - √(R1² - (d1/2)²)` = 0.81 mm しかない。実物のスポット溶接キャップと同じ
「ほぼ平坦な胴付き円筒」に見えるのはこのため。

## ロボット手首許容値との突合せ

FANUC R-2000iC/165F の公表値に対して全項目が余裕を持って収まる
(重心は mount 基準 z=233 mm、J5 回転中心 → フランジ 215 mm で計算):

| | 本ガン | 許容 (R-2000iC/165F) |
|---|---|---|
| 質量 | 95 kg | 165 kg |
| J5 モーメント | 418 Nm | 940 Nm |
| J5 慣性 | 23.8 kg·m² | 89 kg·m² |
| J6 モーメント | 0.3 Nm | 490 Nm |
| J6 慣性 | 4.7 kg·m² | 46 kg·m² |

## visual / collision の分離

- **visual** = `meshes/{body,electrode_arm}.stl`。`tools/generate_meshes.py` が
  生成する手続き的著作物 (trimesh のみに依存、ブーリアン不使用)。寸法定数は
  スクリプト冒頭の GEOMETRY ブロックに集約
- **collision** = URDF のプリミティブ (box / cylinder) のみ、計 12 個。
  **のどの開口を保つのが目的**で、builder がプリミティブを素通しするため
  VHACD で開口が塞がれない。テーパーしたアームは 2 本の円柱で近似し、先端側を
  細くして開口を稼ぐ。可撓物 (ホース・ケーブル) と機体内部のテールには
  collision を与えていない

検証済み (1.5 mm 薄板をのど中心面に差し込んだときの干渉):

| 差込み深さ | 閉 (q=0) | 開 (q=0.26) |
|---|---|---|
| 50 / 150 / 250 mm | 干渉なし | 干渉なし |
| 350 / 400 mm | 干渉 (アーム) | 干渉なし |
| 450 mm | 干渉 | 干渉 (のど奥) |

body ↔ electrode_arm の自己干渉は全可動域 (q=0 / 0.13 / 0.26) で無し。

python weld-gun-x1/tools/generate_meshes.py
