# weld-gun-x1 — サーボスポットガン (X ガン) ドラフト

**状態: draft。** 構造・フレーム・可動は確定だが、寸法・慣性・電極力は
プレースホルダ。botrail 側の著作確定版で数値を更新する
(weld-line-requests.md #2)。

## 構成

- 1 DOF (`electrode_joint`, revolute): 可動電極アーム。**正方向 = 開**。
  q=0 で閉 (電極間クリアランス 5 mm)、q=0.30 rad で先端開き約 95 mm
- リンク: `mount` (root, フランジ接触面) → `body` (ブラケット + サーボ +
  ヨーク + 下アーム + 固定電極) → `electrode_arm` (上アーム + 可動電極)。
  `tcp` = 固定電極先端 (body の固定子リンク)
- collision = visual = プリミティブのみ (のど開口を保つ)

## 主要寸法 (プレースホルダ)

| 項目 | 値 |
|------|-----|
| のど深さ (電極軸〜ヨーク前面) | 315 mm |
| のど開口 (上下アーム間) | 180 mm |
| 電極ストローク (先端) | 約 95 mm |
| 質量 | 35 kg (body 28 + arm 7) |
| 電極加圧力 (specs 宣言値) | 4500 N |
