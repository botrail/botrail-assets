# screw-presenter — 汎用スクリュープレゼンタの見た目

カタログの `botrail/feeder/screw-presenter-m2-m6/r2` (`feeder.screw`、生成器 `screw_feeder`)
が `components[].trim` から参照する表示用 xacro (CC0-1.0)。

- **参照実機は特定していない** — 市場のレール交換式プレゼンタ (M2〜M6、供給 1〜2 s/本) を
  模した独自著作 (`mesh-guard` / `medium-rack` と同じ立場)
- **描くもの**: 板金の筐体、底板、天面後方のホッパ蓋と継ぎ目と取っ手、前面の通気スリット、
  角の留めねじ、操作パネルの縁と電源スイッチ。**レールと供給位置のネストは botrail の
  生成器が描く** (pick 点と一体だから)
- **干渉には入らない**。当たり判定は生成器の筐体の箱 (`<name>/body`) が持つ

原点は **底面中心**。X が筐体の長手、供給位置 (pick 点) のある側が -Y。引数 (メートル):
`length` `width` `height` — 生成器がパックの寸法から渡す。寸法を変えても板厚・ねじ・
スイッチの寸法は伸縮しない。
