# ミスミ RUSA8-5050-W500-D400-JC (垂直多関節ロボットコントローラ用アルミフレーム架台ユニット) — 独自形状の参照モデル

参照実機: **ミスミ 垂直多関節ロボットコントローラ用アルミフレーム架台ユニット RUSA8-5050** の 1 構成 —
**W500・D400・足回り JC (アジャスタ + キャスタ)**。参考重量が公表されている構成を選んだ。
カタログ `misumi/rus/rusa8-5050/r1`。CC0-1.0。メーカー CAD・画像・第三者メッシュを使わず、製品ページ・外形図・構成部品表の数値から著作した。

この製品は幅 W (500〜800) と奥行 D (400〜800) を 1 mm 単位で指定し、足回り 4 通り (N / J / C / JC) から選ぶ寸法指定品。
**このモデルは 1 構成の形だけ**で、ほかの寸法・足回りは表していない。

## フレーム

- root の `base_link` = 枠 (500 × 400) の中心直下の床面、+Z 上。X が幅 W、Y が奥行 D。
- `mount` = `base_link` と同位置・同向き (床に置く契約)。
- `top` = 枠の上面の中心 `[0, 0, 0.134]` (コントローラを載せる面。取付プレートは購入者が用意する)。

## 再生成・表示

```sh
npm --prefix authoring ci
node misumi-rusa8-5050/authoring/export.mjs
node misumi-rusa8-5050/authoring/export.mjs --check
node --test misumi-rusa8-5050/authoring/model.test.mjs
python3 -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765/misumi-rusa8-5050/authoring/` で確認できる。
