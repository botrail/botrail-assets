# trusco-ae-1500 — TRUSCO AE-1500 軽量作業台の見た目

カタログの `trusco/ae/ae-1500/r2` (`structure.table`) が `components[].trim` から参照する
表示用 xacro (CC0-1.0)。メッシュは無く、プリミティブだけで描く。

- **参照実機**: TRUSCO 軽量作業台 AE-1500 (グリーン)。公表値 1500 × 750 × 740 mm、33.5 kg、
  均等荷重 300 kg、アジャスタ M16×2.0 / 20 mm
  ([オレンジブック](https://www.orange-book.com/ja/c/products/index.html?itemCd=AE1500++++++++++++++++++++++++8500))
- **描くもの**: 化粧板 (縁の暗い帯付き)、板より内側に入った折り曲げ C 形鋼の脚 4 本、
  脚の下のアジャスタ (ゴムパッド + ねじ軸)、板の下の幕板と側桟、後ろの低い貫と側の繋ぎ、
  幕板・貫が脚に当たる位置のボルト頭
- **干渉には入らない**。当たり判定は botrail の生成器が置く**内側に寄せた脚 4 本と天板**が持つ
  (パックの `dimensions_mm.inset_length` / `inset_width` = 板の縁から脚の中心まで 85 / 70 mm)

| 項目 | 公表値 | モデル |
|---|---|---|
| 外形 | 1500 × 750 × 740 mm | 同じ (パックの寸法軸) |
| 天板 | 化粧板 | 厚さ 21 mm、縁の帯 (色は写真からの近似) |
| 脚 | 鋼製、板より内側 | 45 mm 角の C 形鋼、縁から中心まで 85 / 70 mm (推定) |
| フレーム | 幕板・貫 | 25 × 70 (幕板)、25 × 60 / 90 (貫) — 断面は推定 |
| アジャスタ | M16、調整 20 mm | φ54 のパッド + φ16 の軸、脚下 35 mm |
| 質量 | 33.5 kg | パックが持つ (見た目は持たない) |

原点は **床レベル・天板の中心**。X が 1500 の辺、Y が 750 の奥行。引数 (すべてメートル):
`width` `depth` `height` `leg` `top_thickness` `inset_length` `inset_width` — 生成器が
パックの寸法から渡す。板は link `top` として描く — botrail は frame の trim に `top` が
あれば自分の天板の massing を隠す。

断面・ボルト位置・アジャスタの形は写真参照の近似で、メーカー CAD ではない。
施工・改造の寸法には使えない。
