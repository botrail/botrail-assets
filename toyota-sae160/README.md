# Toyota Autopilot SAE160 — 独自形状の参照モデル

参照実機: **Toyota Autopilot SAE160**(BT Staxio の自動運転スタッカ、1.6 t、サポートアーム型、
レーザ反射板ナビ)。CC0-1.0。メーカー CAD・第三者メッシュ・図面は取り込まず、公表値から独自著作した。
カタログ ID は `toyota_material_handling/autopilot/sae160/r2`(`vehicle.forklift`、TX Hi-Lo マスト)と
`toyota_material_handling/autopilot/sae160-dx/r2`(DX Tele マスト、[dx/](./dx))、どちらも公開前。旧外観の `r1` は以前のコミットを固定参照する。

(TP-Technical Publications 746908-040, version 17, 2024-01-15; 製品ページ

## 2026-10-09 の visual 改修（新 rev 用）

公式 SAE160 ページと上記データシートを再確認し、同ページの実機写真を目視して
独立した手続き形状として作り直した。参照画像・図面・CAD・ロゴは同梱していない。
出典 URL と確認済み／推定の区分は [provenance.json](./authoring/provenance.json)。

- 電池室と駆動ユニットを分離し、オレンジの多段断面カバー、暗色コンソール、側面ガードを構成
- 中央ティラーの開口した左右グリップ、傾斜した支柱、横長 HMI と支持ステー、5 枚の充電接点を追加
- 後部両角の低いスキャナポッドと保護脚を独立形状化
- マストの中実角棒を内向きの C 断面へ変更し、キャリッジに支持構造付きガイドローラを配置
- 架空の格子バックレストを撤去し、中央開口のキャリッジと細いフォークシャンクへ変更
- フォーク／サポートアームの荷重輪窓を実際の貫通開口とし、素の先端を丸形・下面テーパに変更

TX/DX とも全リンク名・フレーム・軸・可動域・速度・mimic・フリーリフト・車輪位置は main `64904be` と同じ。
2026-10-10 に collision を新しい visual に合わせて改訂した（下記「collision」）。既存 `r1` の公開 SHA は変更していない。

## 表現範囲と仮定

- **フレーム** `base_footprint`(root、サポートアーム輪軸の中点・床)= botrail の Vehicle 原点。実機はこの点を中心に
  その場旋回する(駆動輪を横に切る)ので、公表 Wa は後端角までの距離として再現できる。フォークの向きが +X。
- **関節**: `steer`(駆動輪ヨーク、Z 回り **±90° は仮定**)→ `drive_wheel`(Y 回り)、`castor_left/right`、
  `support_wheel_left/right`(Y 回り、表示のみ)、TX: `mast_lift`(インナーマスト、0〜3.021)+ `free_lift`
  (キャリッジ、0〜1.592)+ `mast_stage`(中段、`mast_lift` の 0.5 倍 mimic)、DX: `mast_lift`(キャリッジ、0〜2.263)+
  `mast_stage`(インナー、0.5 倍 mimic)。段はどちらもアウターマストから吊るので `mast_lift` はそのままフォークの
  移動量になる。
- **フォークとサポートアーム**: 下降時に重なる既存の中実 collision を保存。visual は荷重輪窓と開放された下面を持ち、推定幅 128・高さ 53 mm のアームを包む。
  天板 12 mm・側壁 11 mm・先端下面ランプ 240 mm は独立した推定値であり、実機の板厚ではない。下降姿勢では `carriage` × `base_link` と `carriage` × サポートアーム輪
  (表示メッシュ)が干渉として読まれる — カタログのレシピで許容対にする。上げれば離れる。
- **公表値のない形**(README 冒頭の表にない値は全部推定): 電池室の高さ 1.10 m と前面の位置(フォーク面から 240)、
  マストの C 断面・壁厚・間隔、ローラ、キャリッジ板、シャンク包絡(h4 − h23 を継承)、スキャナの筐体、
  コーナースキャナの位置、キャスタ位置(駆動輪軸上を継承、写真ではより後方に見える)、ティラーの形、充電板の側。
- **collision**(2026-10-10): 車体は駆動部の箱・サポートアームの箱に、中央のティラーと頭部・コンソール上面の箱を足した。
  アウターマストはチャネル 2 本に、描いた位置(チャネルの後ろ)の足元・頭部の板、スキャナポストとその根元・窓、HMI のクロスバー、
  それを支える斜めの 2 本のステー(傾けた箱)、ビーコン、足元のピン、上端のシュラウドを足した。中段・内側マストはチャネルと
  下側の横材・耳(上端の横材は描いていないので持たない)。キャリッジは板・タイ・スタイル・シャンクを板の背面からフォーク面(x = 0)・
  シャンク上端(h4 − h23)までの 1 個の箱で包み、ガイドローラの組(ローラ・軸・取付金具)を内側マストのチャネル内の箱で包む。
  例外は、フォーク面から 10 mm 出ているシャンクの丸い前端と、中段のチャネル包絡に 3.5 mm 入るローラ軸の端だけ
  (箱はそれぞれフォーク面・包絡の 0.5 mm 手前で止める)。接触・干渉・安全評価には実機寸法で別途検証が必要。
- **装備の選択**: 長い円柱ナビポストを持つ構成。短ポスト RS カメラ支柱、+41 mm の機械式フォーク先端バンパー、
  乗車台は混ぜていない。透明マストガードはこの opaque OBJ/MTL 系では省略。
- **動く機構**: チェーン、油圧シリンダ、ホースの経路と伸縮則は未同定のため省略。動くリンクを固定の飾りで
  つないでいない。キャリッジローラも形状推定で、実機接触・荷重経路の解析結果ではない。支持方法を
  確定できない段間ローラは省略した。マストの連結部は各可動レールの下部に置き、固定スキャナと親段・キャリッジの通過経路を避ける。
  この連結位置・形状は独立した近似で、実機の溶接構造を保証しない。
- **定格の注意**: 1,600 kg は全揚高で許される値ではない。公式自動運転表では 650 mm 荷重中心・4,700 mm 揚高で
  690 kg。今回レシピ性能値は変更しておらず、安全・耐荷重を保証するモデルではない。
- 車輪 5 個は表示のみ(collision 無し)。車輪の回転と操舵は botrail の `bt.Wheels`(`drive: tricycle`、
  `steer={"drive_wheel": "steer"}`)が走行から導出する。
- 質量・重心・慣性は未同定のため書かない(レシピが車両重量を持つ)。

## 再生成・表示

```sh
npm --prefix toyota-sae160/authoring ci
npm --prefix toyota-sae160/authoring run export     # meshes/*.obj + urdf/toyota-sae160.urdf、dx/ 以下に DX Tele
npm --prefix toyota-sae160/authoring test
python3 -m http.server 8737 --bind 127.0.0.1        # http://127.0.0.1:8737/toyota-sae160/authoring/ (?mast=dx)
```

## 検証

`npm test` は TX/DX の URDF SHA-256、72 通りの lift/steer/spin、フリーリフトの切替、
車輪の接地、303 姿勢のスキャナ／横梁の掃引離隔、支持構造の接続、貫通窓と C 断面、フォーク先端の下面テーパ、全 visual の閉鎖性・正体積・有限法線、
OBJ の厳密な面コーナー保持と再生成一致を確認する（20 テスト）。`npm run check` は書き込みなしで生成物を比較。

静止画は `authoring/render_review.py` による Blender 4.x の実 OBJ/URDF レンダー。
この環境ではブラウザ UI の起動・操作は未検証。静止画や Node 検証を UI 動作確認とは扱わない。

```sh
node toyota-sae160/authoring/export-materials.mjs > /tmp/toyota-materials.json
blender -b -t 4 --python toyota-sae160/authoring/render_review.py -- \
  toyota-sae160/urdf/toyota-sae160.urdf /tmp/toyota-full.png \
  --view extended --materials /tmp/toyota-materials.json \
  --pose '{"free_lift":1.592,"mast_lift":3.021,"steer":1.57079632679}'
```
