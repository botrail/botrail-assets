参照実機: **Toyota Autopilot SAE160**(BT Staxio の自動運転スタッカ、1.6 t、サポートアーム型、
レーザ反射板ナビ)。CC0-1.0。メーカー CAD・第三者メッシュ・図面は取り込まず、公表値から独自著作した。

`toyota_material_handling/autopilot/sae160-dx/r1`(DX Tele マスト、[dx/](./dx))。

## 表現範囲と仮定

- **フレーム** `base_footprint`(root、サポートアーム輪軸の中点・床)= botrail の Vehicle 原点。実機はこの点を中心に
  その場旋回する(駆動輪を横に切る)ので、公表 Wa は後端角までの距離として再現できる。フォークの向きが +X。
- **関節**: `steer`(駆動輪ヨーク、Z 回り **±90° は仮定**)→ `drive_wheel`(Y 回り)、`castor_left/right`、
  `support_wheel_left/right`(Y 回り、表示のみ)、TX: `mast_lift`(インナーマスト、0〜3.021)+ `free_lift`
  (キャリッジ、0〜1.592)+ `mast_stage`(中段、`mast_lift` の 0.5 倍 mimic)、DX: `mast_lift`(キャリッジ、0〜2.263)+
  `mast_stage`(インナー、0.5 倍 mimic)。段はどちらもアウターマストから吊るので `mast_lift` はそのままフォークの
  移動量になる。
- **フォークとサポートアーム**: 下降時、フォーク(70 厚)はサポートアーム(高さ 68、幅 154)に**被さって重なる**
  (実機どおり)。衝突箱はどちらも中実なので、下降姿勢では `carriage` × `base_link` と `carriage` × サポートアーム輪
  (表示メッシュ)が干渉として読まれる — カタログのレシピで許容対にする。上げれば離れる。
- **公表値のない形**(README 冒頭の表にない値は全部推定): 電池室の高さ 1.10 m と前面の位置(フォーク面から 240)、
  マストのチャネル断面と間隔、キャリッジ板、バックレストの格子(高さは h4 − h23 から)、スキャナの筐体、
  側面スキャナの位置、キャスタの位置(駆動輪軸上)、折り畳んだティラーの形、充電板の側。
- 車輪 5 個は表示のみ(collision 無し)。車輪の回転と操舵は botrail の `bt.Wheels`(`drive: tricycle`、
  `steer={"drive_wheel": "steer"}`)が走行から導出する。
- 質量・重心・慣性は未同定のため書かない(レシピが車両重量を持つ)。

```sh
npm --prefix toyota-sae160/authoring ci
npm --prefix toyota-sae160/authoring run export     # meshes/*.obj + urdf/toyota-sae160.urdf、dx/ 以下に DX Tele
npm --prefix toyota-sae160/authoring test
python3 -m http.server 8737 --bind 127.0.0.1        # http://127.0.0.1:8737/toyota-sae160/authoring/ (?mast=dx)
```
