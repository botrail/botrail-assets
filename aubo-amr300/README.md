# AUBO-AMR300 — 独自形状の参照モデル

参照実機: **AUBO Robotics AUBO-AMR300**(海纳 / Haina 系列、差動 2 輪 AMR、可搬 300 kg)。CC0-1.0。
メーカー CAD・第三者メッシュ・図面は取り込まず、公表値から独自著作した。
カタログ ID は `aubo/amr/amr300/r1`(`vehicle.amr`)。

出典:

- [AMR海纳系列 AUBO-AMR300 製品ページ (参数)](https://www.aubo-robotics.cn/products/aubo-amr300)(2026-09-17 参照)。
  AUBO の下載中心 (数模文件) に AMR の CAD は無く (iS 系のみ)、公開 URDF も無い。
- [六合エレメック (日本代理店) の AUBO-AMR300S 紹介](https://robot.rokugo-g.co.jp/)(同日参照)。
  外形・自重・可搬は公式と同値、最高速度だけ 1.5 m/s と異なるので公式の 1.3 m/s を採る。
- 開発者サイトで配布される複合ロボット取扱説明書は複製禁止条項付きのため、**寸法ソースには使っていない**
  (CONTRIBUTING の規約)。

## 表現範囲

- `base_link` = スカート + 上部シェル + 上面プレート + スキャナ・非常停止・前面窓・安全エッジの意匠。
  collision はスカート箱(地上高 25 → 215 mm、各面 30 mm 内側)と上部シェル箱(215 → 600 mm、1,000 × 700)の 2 個。
- 車輪 6 個は表示のみ(collision 無し)。車両は botrail の Vehicle としてシャシの箱で通路検査され、
  車輪の回転は `Scene.set_vehicle_wheel` に半径(0.080 / 0.050)を渡して付ける。
- フレーム: `base_footprint`(root、接地面)、`deck`(上面中心、+Z)、`load_surface`(負荷面中心)、
  `arm_mount`(アーム取付、+X = 前方)。いずれも z = 0.600。
- 光の帯・スキャナ窓・前面窓・非常停止は意匠の近似で、センサの視野や保護フィールド、安全機能を表さない。
- +X が前方(アームを載せる側)。スキャナ・非常停止の前後左右は写真の解釈で、実機の配置とは異なり得る。

## 再生成・表示

```sh
npm --prefix aubo-amr300/authoring ci
npm --prefix aubo-amr300/authoring run export     # meshes/*.obj + urdf/aubo-amr300.urdf
npm --prefix aubo-amr300/authoring test
python3 -m http.server 8737 --bind 127.0.0.1   # http://127.0.0.1:8737/aubo-amr300/authoring/
```
