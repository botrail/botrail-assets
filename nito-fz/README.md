# 日東工業 FZ スタンダード / FCX-Z基台 — visual trim

実在するFZシリーズ・スタンダードタイプを参照したCC0独自著作モデル。
メーカーCAD・寸法図・写真を複製しない。内部実装のない閉扉外観モデル。

| 項目 | 公表値 | モデル |
| --- | --- | --- |
| 本体W | 600 / 700 / 800 / 1000 / 1200 mm | 同じ |
| 本体H | 1600 / 1900 / 2100 / 2300 mm | 同じ |
| 本体D | 400 / 500 / 600 / 800 mm | 同じ |
| 扉形式 | W800以下は片扉、W1000以上は両扉 | 同じ、フラットハンドルは1個 |
| 板厚 | ボデー1.6 / 扉2.3 mm | 外側スキンは同じ厚さ |
| 全高 | 本体H＋52 mm | 吊り金具が屋根から52 mm |
| 基台 | FCX-Z、高さ50/100、板厚3.2/4.5 mm | 同じ高さ・板厚の開口チャンネル近似 |
| 塗色 | ライトベージュ5Y7/1 | 画面上の近似色 |

出典: [FZ公式製品ページ](https://ntec.nito.co.jp/content/ppreview.html?proid=6066)、
[FCX-Z基台](https://ntec.nito.co.jp/content/ppreview.html?code=C683-C605-C8824-S6198)。

`visual/body.urdf.xacro` は `width`, `depth`, `height`（本体）, `base` をmで受け取る。
原点は床上中央、正面−Y、Zが上。基台なしは `base=0`。
既定では800×600×2100＋基台100＋吊り金具52 = 全高2252 mm。
`equipment-common/` と `meshes/lifting-eye.stl` を同梱すること。

意図的な近似: 吊り金具の外径40・内径20 mm、屋根端から40 mmの配置、
ハンドル長・パネル継目・基台フランジ幅は未寸法化部分の外観推定。
吊り金具の穴と基台中央は実際に開いている。扉は固定、見えない内部は簡略化している。
IP等級、扉の開放軌跡、吊上げ荷重、気密性、熱設計はこのモデルでは検証できない。
本体・基台・鉄製基板の質量はカタログのBOM値に従い、表示形状から再推定しない。
衝突は本体ボックスと吊り金具高さ分の保守的な上部ボックスで判定する。

吊り金具の再生成: `npm --prefix authoring ci` の後、
`node nito-fz/authoring/export.mjs`。`--check` はSTL一致確認、
`--usd /tmp/nito-fz-eye.usda` は同じ形状のthree-usd-robot出力。
