## 表現範囲

- `base_link` = 車体(スカート・白いシェル・バンパ・灯具・窓)。衝突は外形の箱 1 つ(地上高から 380 mm まで)。
- `turntable` = 上面のターンテーブル(表示のみ)。利用側が棚を持ち上げた状態を描くときは、このリンクの表示を
  持ち上げ量だけ上げる。
- フレーム: `base_footprint`(root、接地面)、`deck`(ターンテーブル上面 +Z、下降位置)。
- 質量・慣性は未同定のため持たない。
