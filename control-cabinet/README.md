# control-cabinet

制御盤キャビネット (盤用キャビネット) の**見た目**を持つアセット (CC0-1.0)。
カタログの盤用キャビネットのスペックパック (`structure.cabinet`) が
`components[].trim` から参照する。

- **メッシュは無い。プリミティブの xacro だけ** — 盤用キャビネットは W×H×D を
  型式マトリクスから選んで買う製品なので、1 枚の xacro が売られている全寸法を描く
- **参照実機は特定していない** — 国内で一般的な自立形キャビネット (ライトベージュ塗装、
  片扉/両扉、チャンネルベース基台) を模した独自著作
- **干渉には入らない**。当たり判定は botrail が置く本体 (+基台) の箱が持ち、
  このファイルはその見た目と扉板・ハンドルを描く

## ファイル

| | 引数 (すべてメートル) | 描くもの |
|---|---|---|
| `visual/body.urdf.xacro` | `width` `depth` `height` `base` | 基台 (base=0 なら無し)・本体・扉板・ハンドル。**扉の枚数は幅から決まる** (1000 mm 以上は両扉) |

原点は **床レベル・本体の平面中心** (扉面は -Y)。基台の高さは `base` で渡り、
本体はその上に載る。
