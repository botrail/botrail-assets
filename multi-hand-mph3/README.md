# multi-hand-mph3

マシンテンディング用の **複合ハンド(MPH-3)** の自作アセット。CC0-1.0。

1 枚のフランジプレートに 3 つの工具を載せ、ロボットが手首を向け替えて使い分ける:

```
ロボットフランジ (ISO 9409-1-50-4-M6)
  -> [mph3_plate .. mph3_gripper]   このプレート (12 mm)。+Z にグリッパのスタック
                                    (カップリング + 平行グリッパ) が載る
  -> mph3_pusher .. mph3_pusher_tip 押釦用ピン ø12 × 60、プレート +X 側へ (先端 100 mm)
  -> mph3_fork .. mph3_fork_tip     扉ハンドル用フォーク (プロング 80、間隔 30、座 50)、-X 側へ
```

## 参照実機

FANUC の ROBODRILL + CRX 展示セル(ROBODRILL α-D14MiB5 の側面に台車搭載の CRX、
手先に「扉用・ワーク用・押釦用」の 3 機能を組み合わせたエンドエフェクタ)。
写真から読める構成(1 ブラケット 3 工具、手首の向け替えで切替)を、公開規格の
フランジ寸法の上に**当方の設計値**で置いたもの。実機の寸法は非公開。

### 公開データで確定している値

| 面 | インタフェース | 出典 |
|---|---|---|
| ロボット側 | **ISO 9409-1-50-4-M6**(外径 63 / ボルト円 50 × 4-M6) | 公開規格 |
| グリッパ側 | 同上(`mph3_gripper` 面にカップリングを載せる) | 同上 |
| 押釦 | ISO 22 mm 押釦の操作行程 2.6 mm・キャップ ø28.5 に対しピン ø12 | 22 mm 押釦の公開データ |

### 設計値(公開データが無い部分)

- **プレート ø80 × 12 mm**(ISO 呼び 50 のフランジ外径に余裕を見た径、M6 座ぐりが成立する厚)
- **ピン ø12 × 60 mm**、プレート縁 (x = 40) から +X へ。先端はプレート中心から 100 mm
- **フォーク** プロング 10 mm 角 × 80 mm、間隔 30 mm(20 mm 角のハンドル棒 + 片側 5 mm)、
  座はクロスバーから 50 mm。プレート縁 (x = −40) から −X へ
- ピン・フォークはプレート面から 22 mm(工具中心)の高さ

## 座標系

botrail カタログ規約: Z-up / メートル。root リンク `mph3_plate` = ロボットフランジ接触面、
+Z が外向き。`mph3_gripper` がグリッパスタックの取付面(`flange_frame`)。
各工具の先端フレーム(`*_tip`)は +Z が工具軸 = 接近方向。

## 再生成

`tools/generate_urdf.py` が botrail の `bt.tools.multi_tool_urdf` からこの URDF を書き出す。
セル側で Python で組んだ同じレイアウトのハンドと、カタログ品が同一形状になる。
