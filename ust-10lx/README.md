# ust-10lx

測域センサ (北陽電機 UST-10LX フォームファクタ) の自作マッシングモデル (CC0-1.0)。

> **北陽電機の CAD ではない。** 北陽の 2D/3D CAD は会員ログインの先にあり再配布
> 条件を判断できないため、公開外形図と仕様書の公表値に合わせて独自に著作した
> 簡略形状である。実寸 CAD が要る用途には北陽の会員ダウンロードを使うこと。

## 寸法の根拠

出典: 北陽電機 製品ページ (UST-10/20LX) の外形図 PNG と仕様書 C-42-04077。

| 項目 | 値 | 出典 |
|---|---|---|
| 外形 | 50 × 50 × 70 mm (本体のみ) | 公表値 |
| 下部筐体 (アルミ) / 光学窓 | 高さ 35 / 窓 28.7 | 外形図 |
| 走査中心 (受光部) | 底面から 47.4 mm | 外形図 |
| 底面取付 | 4-M3 深さ 6 (40 × 40)、2-φ3 位置決め | 外形図 |
| 質量 | 130 g (ケーブル除く) | 公表値 |
| 角丸・上部の丸み・窓帯の凹み・ケーブル付け根 | — | **当方設計** |

## 座標系

- 原点 = `mount` = **底面中心** (実機は底面 4-M3 で取付)
- `laser` = 走査焦点、底面の 47.4 mm 上。+X = 走査正面 (0°)、スキャン面 = XY
  (ROS laser 規約 = botrail の lidar 規約)。ケーブルは -X (背面)

## 再生成

```sh
python ust-10lx/tools/generate_meshes.py   # 依存: trimesh
```

`meshes/{base,head}.stl` (メートル単位, Z-up) が更新される。collision は URDF の
プリミティブ 2 箱で、メッシュに依存しない。
