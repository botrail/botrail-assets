# tool-changer-a1

空圧ロボットツールチェンジャ (マスタ側 + ツール側) の自作アセット。CC0-1.0。

カタログに `tool_changer` カテゴリのモデルが 1 つも無かったのを埋めるために著作した。
ベンダー製チェンジャはオープンな 3D モデルが存在しないため (ATI / SCHUNK / Stäubli を確認)、
**実機を 1 つ参照モデルに定め、その公表値に寸法を合わせた独自著作**にしてある。

## 参照実機

**SCHUNK SWS-011** — 空圧クイックチェンジシステム。マスタ側とアダプタ側が別部番で、
本アセットの 2 パッケージ構成とそのまま 1:1 対応する。

| | 参照実機 | 出典 |
|---|---|---|
| マスタ | [SWK-011-000-000](https://schunk.com/us/en/automation-technology/tool-changer/sws/swk-011-000-000/p/000000000000302316) | SCHUNK 公式製品ページ 技術データ |
| アダプタ | [SWA-011-000-000](https://schunk.com/us/en/automation-technology/tool-changer/sws/swa-011-000-000/p/000000000000302317) | 同上 |

### 参照実機から採った値

| 項目 | SWS-011 の公表値 | 本アセット |
|---|---|---|
| マスタ 板厚 | 15.5 mm | **15.5 mm** (一致) |
| アダプタ 板厚 | 20.6 mm | **20.6 mm** (一致) |
| 結合時 積み高さ | 36.1 mm | **36.1 mm** (一致) |
| 最大可搬 | 16 kg | **16 kg** (一致) |
| ロック力 | 1100 N | **1100 N** (一致) |
| 繰返し精度 | 0.015 mm | 0.015 mm (メタデータのみ) |
| エア通し | 6 ポート (6x M5) | **6 ポート** (一致) |
| 使用圧 | 4.5–6.9 bar | メタデータのみ |
| 許容芯ずれ | XY ±1 mm / 角度 ±2° | 食い付き角の設計根拠に使用 |

**マスタの方がアダプタより薄い** (15.5 < 20.6) のが実機の姿。直感に反するので特記しておく
— 初版はここを逆に作っていた。

### 参照実機から意図的に変えた点

| 項目 | SWS-011 | 本アセット | 理由 |
|---|---|---|---|
| 外径 | ø50 | **ø63** | 下記のインタフェース変更に伴う |
| 取付インタフェース | SCHUNK 独自 "S7" ボルトパターン | **ISO 9409-1-50-4-M6** | ø50 の胴には ISO 呼び 50 のボルト円 (P.C.D 50) が載らない。**カタログ収録済みの UR5e / TM5-900 / 2F-85 / gripper-coupling と直結できること**を優先した |
| マスタ質量 | 0.13 kg | 0.15 kg | 外径拡大分の割り増し (増えるのは外周リング部なので控えめに見積もり) |
| アダプタ質量 | 0.09 kg | 0.11 kg | 同上 |

ISO 呼び 50 の値 (外径 63 / P.C.D 50 x 4-M6 / 位置決め径 31.5 / ダウエル 6) は、
OMRON i837 (Techman TM5) のフランジ図
`P.C.D ø50.00 / M6 x4 / ø63.00 h8 / ø31.50(H7) / ø6.00(H7) x2` と一致することを確認済み。

**外観 (ボス径・ポート配置・ボール数・面取り・ベアリングレース形状) はすべて独自著作。**

### ATI QC-11 を参照実機にしなかった理由

同クラスの ATI QC-11 も可搬 16 kg / ロック力 1100 N で数値が一致するが、参照実機には
していない:

1. **基本形の寸法図が公開文書に無い。** 入手できる Quick-Change マニュアル
   (9610-20-1000) の §3 Specifications は「寸法は製品カタログとサイト参照」で数値ゼロ。
   図面が載っている §9.3 は中空手首マウント + A15 モジュール版で積み高さ 78 mm、
   基本形の 52.4 mm とは別構成
2. **同マニュアルに複製禁止・第三者開示禁止の条項**がある

SCHUNK を選んだのは、**公式製品ページに寸法が制限なしで載っている**ため。

## 構成

対になる 2 枚の板を別 URDF にしてある。チェンジャの本質は**分離できること**なので、
1 つの剛体にまとめず、それぞれ独立に着脱できるようにした。

```
ロボットフランジ
  -> [master.mount .. master.coupling]   tool-changer-a1-master.urdf  (15.5 mm)
  -> [tool.mount   .. tool.flange]       tool-changer-a1-tool.urdf    (20.6 mm)
  -> エンドエフェクタ                                      結合時 合計 36.1 mm
```

ツール側の上面は**ロボットフランジと同じ ISO 9409-1-50-4-M6 を提示する**ので、
カタログ収録済みの `robotiq/coupling/gripper-coupling` や `robotiq/2f/2f-85` を
ロボット直付けと同じ作法でそのまま積める。

| | master | tool |
|---|---|---|
| 高さ | 15.5 mm | 20.6 mm |
| 質量 | 0.15 kg | 0.11 kg |
| root | `mount` (ロボット側フランジ面) | `mount` (マスタとの結合面) |
| 提示面 | `coupling` (z=15.5 mm) | `flange` (z=20.6 mm) |
| 機構 | カムボス ø25 + ロッキングボール 6 | 受け穴 + ベアリングレース |

## 生成

```sh
python tool-changer-a1/tools/generate_meshes.py
```

visual は回転体 (閉じた `(r, z)` 輪郭) で作る。旋盤加工品なので回転体にすれば
中ぐり (通し穴 ø10 / 位置決め穴 ø31.5 / 受け穴 ø25.5) がブーリアン無しで出せる。
非軸対称のディテール (ダウエルピン・エア継手・側面ポート・ロッキングボール) は後付け。

collision は URDF プリミティブのみ (板 + カムボス + スピゴット + 側面ポート)。
ダウエルピンは相手側の穴に入る消耗形状なので collision には出していない。
