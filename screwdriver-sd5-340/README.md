# screwdriver-sd5-340

協働ロボット用 **ねじ締め工具(SD5-340 級)** の自作包絡アセット。CC0-1.0。

```
ハンド / ロボットフランジ (ISO 9409-1-50-4-M6)
  -> mount            この面 (root)。+Z が工具軸 = 工具の向き
  -> body             モータ胴 ø86 × 200
  -> nose             ノーズ ø30 × 50
  -> [shank 0..55 mm] -> bit   ビット ø8 × 60 (工具自身の送り軸 = prismatic 関節)
  -> tip              ビット先端。X 軸半回転で反転し、+Z が「先端 → 工具本体」方向
```

## 参照実機

協働ロボット向けねじ締め工具の公開仕様(OnRobot Screwdriver の製品頁・データシート転記値):
トルク 0.15〜5 N·m、ねじ M1.6〜M6・長さ 50 mm まで(ねじ部 35 mm)、出力回転数 340 min⁻¹、
**シャンク行程 55 mm**(工具自身がねじを送る)、2.5 kg、308 × 86 × 114 mm、IP54。
CAD は使っていない — 公開値から当方が置いた**包絡**で、意匠には寄せていない。

### 公開データから採った値

| 項目 | 値 | 出典 |
|---|---|---|
| 全長 | 308 mm(胴 200 + ノーズ 50 + ビット 60 の設計割付) | 製品データシート |
| 幅 | 86 mm(胴の径に採用) | 同上 |
| シャンク行程 | 55 mm | 同上 |
| トルク / ねじ径 / ねじ長 / 回転数 / 質量 | 0.15〜5 N·m / M1.6〜M6 / ≤ 50 mm / 340 min⁻¹ / 2.5 kg | 同上 |

### 設計値(公開データが無い部分)

- ノーズ ø30 × 50、ビット ø8 × 60(六角ビット 対辺 4 mm = M5 の ISO 4762 相当)
- 取付面は ISO 9409-1-50-4-M6 を仮定(実機はクイックチェンジャ経由)

## 座標系

botrail カタログ規約: Z-up / メートル。root リンク `mount` = 取付面、+Z が工具軸。
`tip` は先端で X 軸半回転して +Z が工具本体側を向く(`PathTarget.tool_axis` 規約、
スピンドル `spindle-emsf3060` と同じ)。`bit` だけが「ねじに触れてよいリンク」で、
胴とノーズは通常の干渉検査に入る。

## 再生成

`tools/generate_urdf.py` が botrail の `bt.tools.screwdriver_urdf` からこの URDF を書き出す。
セル側で Python で組んだ同じ寸法の工具と、カタログ品が同一形状になる。
